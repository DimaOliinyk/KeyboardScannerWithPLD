# KeyboardScannerWithPLD
## Схема сканування матричної клавіатури для мікроконтролерів на основі PLD
### 1. Технологія PLD
Programmable logic device (PLD) – (програмований логічний пристрій) це
електронний компонент який використовується для створення схем, які можна
конфігурувати та змінювати користувачем. Цим пристроєм можна замінити
дискретні логічні елементи з фіксованими функціями.
Принцип роботи полягає у тому, що PLD складається з ряду логічних елементів,
ці логічні елементи приєднуються до матриці з’єднань до якої підключаються
входи, які являють собою буферні входи з інвертуючим та неінвертуючими
виходами.

Якщо у правильних точках матриці створити з’єднання, то можна утворити
функцію задану користувачем. Як матрицю з’єднань використовують елемент
пам’яті. У моделях PLD PAL (programmable array logic) використовувалась
одноразова пам’ять. У моделях PLD GAL (generic array logic) використовувалась
пам’ять EEPROM, що дозволяє перепрограмувати функцію кілька разів.
Наприклад, конфігурації «виключного або» створюється таким чином: Із таблиці
істинності впишемо функцію: 𝑌 = 𝐴 ∙ 𝐵̅ + 𝐴̅∙ 𝐵. Рядки у матриці працюють як
послідовне з’єднання і відповідають логічному «і», а всі рядки під’єднуються до
логічного «або». Таким чином в одному рядку створимо з’єднання A та 𝐵̅, а в
іншому А̅ та B. І з’єднавши з логічним «або» отримуємо потрібну функцію.
